# 主 Agent 中心的自适应研究与集成

本轮改进的主体是主 Agent 的有效设计上下文与执行效率，不是多 Agent 自治设计系统。研究员完整运用既有 UI Spec 方法进行多轮探索、真实观察、比较、来源追踪与提纯；主 Agent 在这些高质量入口上继续关键视觉判断、选择、试装和整体质量验证。来源和设计边界已经明确的集成可以委派，责任不转移。

正式 SPEC、研究任务与回归范围分别判断。小型但高影响的视觉对象可能需要宽范围研究；成熟系统已覆盖的普通页面可能完全无需委派。新发现可以改变正式粒度，但只有主 Agent 综合判断，并保留原有未解决承诺。

四类角色均在用户显式执行安装时默认安装；研究员与有界集成员是主要角色，独立挑战与复杂 GUI 观察按需调用、不是必经阶段。普通浏览和视觉操作仍由所有相关 Agent 正常使用。研究任务通过自然语言传递意图和边界，不规定字段模板或资源配额。

提纯保留真实视觉入口、候选间的实质差异、源实现、观察条件、反例和未知；不把优秀但无源码的参照错误标为可集成实现。主 Agent 不重做全部低价值点击，但必须亲自看清关键候选和集成结果。资源获取、实际采用和视觉品质保留分别成立。

主 Agent 通过现有证据地图吸收结果，不另建当前设计权威。对话只呈现重要发现、选择、首次结果及显著差距。八份公共参考读取要求与 W1–W3 有界原创规则不变；无子 Agent 或 GUI 工具时保持单 Agent 专业工作路径。
