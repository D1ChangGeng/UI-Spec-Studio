# UI Spec Studio｜内容设计、UX Writing 与文字视觉

文字内容是产品信息、交互行为与视觉构图的共同材料。新的内容设计方法以用户任务和真实事实为起点，决定用户何时需要理解什么，哪些页面和组件承担信息，采用怎样的语言风格，以及排版如何与实际布局协同。

## 专业能力

| 维度 | 决策对象 | 预期效果 |
|---|---|---|
| 内容需求 | 用户已有认知、目标与所需事实 | 信息在关键决策点可获得 |
| 信息分布 | 页面、区块、标题、标签、帮助和状态职责 | 连续的 UX 阅读与操作路径 |
| 产品语言 | 同类产品术语、内部业务概念与用户心智 | 熟悉、准确、一致的表达 |
| Voice & Tone | 稳定品牌个性和情境语气 | 有辨识度且适合各类操作 |
| UX Writing | 标签、动作、说明、反馈和错误恢复 | 用户知道下一步能做什么 |
| Typography | 文字长度、字体、换行、密度和视觉重量 | 自然的阅读节奏及空间平衡 |
| Localization | 各语言实际语义、语言长度和界面变体 | 内容与构图在多语言下完整可用 |
| 真实验证 | 行为、权限、价格、状态与呈现事实 | 界面语言与实际结果一致 |

## 与现有 Skill 的关系

第八份共同参考 [`content-design.md`](../skills/ui-spec/references/content-design.md) 负责具体判断方法；其他参考只保留其对应层次的责任。它与成熟设计资源探索、素材工程和视觉原则一起工作：优秀产品提供内容表达参照，当前产品提供真实语义与业务事实，页面设计和实际渲染共同决定最终结果。

**Init** 恢复业务语言与内容来源；**Shape** 定义内容需求、分布和写作方向；**Iterate** 写入真实文本，协调视觉并进行状态验证；**Audit** 检查阅读路径、跨页面一致性及完整状态；**Finish** 连接真实事实、服务结果和本地化内容。
