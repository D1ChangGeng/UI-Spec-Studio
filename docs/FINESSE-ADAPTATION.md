## Deliberate non-transfers

Do not import a single register's palette, mandatory texture, universal font
recipe, numerical spectacle ranges or product-category aesthetic ceiling. Do
not treat recurring forms as intrinsically bad. Judge an unresearched default,
its task fit and actual craft instead. Do not inherit a one-engine-first ladder,
fixed byte cost or universal frame target as a technical fact. The same effect
can have several valid routes with different constraints and measured costs.

A source's numeric example is not an accessibility standard. Relevant standards
and current platform contracts remain independent: [W3C contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html),
[MDN touch-action](https://developer.mozilla.org/en-US/docs/Web/CSS/touch-action),
and [Motion drag](https://motion.dev/docs/react-drag) were checked for the scoped
contrast, gesture and API statements. Pointer Events gesture ownership cannot
be recovered by simply changing touch-action after a gesture has begun.

## Practical resource observations

Primary discovery pages were read for React Bits, Vue Bits, Magic UI, Aceternity
and Inspira. A component-level card study additionally inspected acquired actual
React Bits Spotlight renders and a Magic Card documentation render. A Tilted
Card public capture showed a loading placeholder; its live visual behavior was
not certified from that capture. An exact-source local application supplied a
separate candidate trial. These scopes do not establish library-wide quality.

React Bits source used in the study is fixed at
`e12c22192ac7b4b452c5e2feb9b586d74765d696`. Its acquired license includes
**MIT + Commons Clause**, including restrictions on redistribution of components
as components. Consequently the release does not bundle the source components
or a showcase corpus. Source provenance and application findings are retained;
any separately shared working application keeps its license and stated scope.
This is source-term handling for this study, not general legal advice.

Additional research inspected prompt-kit's prompt-input and tooltip source at
`5a9496635cc0e1bf7679fe2a9e35d9b36b99c08a` and the React Bits Aurora directory.
They remained source/documentation research and were not installed, visually
validated or adopted in the bounded card application. Their names are not
counted as additional successful adoptions.
