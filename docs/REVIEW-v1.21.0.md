### Representative behavioral change (old vs new)

- **Cold-start brownfield re-entry after external commits**: Under `v1.20.6`, a fresh host session had no explicit tri-way drift protocol separating compatible refactors, authoritative backend contract changes, ad-hoc visual hotfixes and requirement pivots; an agent could either re-litigate settled visual foundations or overwrite an engineer's accessibility/security hotfix while restoring design tokens. Under `v1.21.0`, `workflow.md` and `integration.md` require establishing the Continuation Baseline first, inheriting settled commitments under matching conditions, inspecting live renders and Git history before editing, preserving landed functional/accessibility/security fixes, and repairing visual craft and default-deny provenance on top.
- **Multi-month record growth and shared-system upgrades**: Under `v1.20.6`, `evidence-map.md` defined the three-tier memory model (`Current Design Model -> Meaningful Revisions -> Evidence Archive`) without explicit compaction invariants or named debt classes, and `component-sourcing.md` / `verification.md` lacked staged coexistence-bridge and seam-regression guidance. Under `v1.21.0`, `Current Design Model` compacts to `O(active product + open obligations)` while Debt Anti-Evaporation guarantees none of the four obligation classes can vanish across compaction or SPEC repartitioning, and shared-system upgrades follow anchor-slice validation, scoped W1–W3 bridges, legacy decommission tracking and dependency-scoped regression across primary slice, seams and extremum consumers.
