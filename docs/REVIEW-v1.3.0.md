## File-level changes

The six common references remain the shared professional foundation. Sourcing is
rewritten as the complete method; workflow and analysis make its use proactive.
Visual/interaction references cover assembly quality; verification and integration
carry the distinction through real behavior. Examples demonstrate conditional use.

New installable files are the structured catalog, generated resource map, optional
read-only lookup and optional adoption-note template. The catalog preserves all
37 original resource IDs, primary-source URLs and research dates, plus seven
mechanisms. Working descriptions are English; retained Chinese aliases assist
lookup. The source snapshot hash is stored in catalog provenance.

Maintainer changes include a map generator and resource regression tests. User
changes include English/Chinese README guidance, installation/usage documentation,
this review and version notes. Existing artwork and its responsive variants remain
the approved publishing language. Git tracks the source changes.

## Scenario reasoning

Review paths cover an open brief, a precise selected component, routine continuation,
an already suitable incumbent, an unavailable source, a misleading export, a
cross-framework candidate, paid assets, multiple animated parts, a static
publication and real backend state. Each path retains the agent's initiative,
project direction, actual permission boundary and evidence scope.

The shared Skill supplies methods and data. The host provides tools and execution;
project records own specific decisions. Catalog lookup and package tests establish
their exercised mechanics. Design quality and integration validity are assessed
through the actual project's renders and tasks.
