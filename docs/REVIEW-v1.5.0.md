## Logical scenarios

| Situation | Expected behavior |
|---|---|
| Routine action icon | Reuse suitable family, retain semantics, coordinate optical weight and hit target |
| Third-party service mark | Identify actual service, inspect owner guidance and exact allowed artwork |
| Original identity from brand references | Extract form relationships, develop distinct expression, preview at actual sizes |
| Artistic wordmark | Deliberate recognition in its identity role; readable text and accessible name elsewhere |
| Bilingual interface | Check true characters, fallback/metrics and loading; preserve licensed font source |
| Hero subject changes layout | Inspect asset early, revise crop/composition and adjacent copy together |
| 2D-to-3D | Preserve source; distinguish inferred hidden geometry and required runtime views |
| Procedural or hybrid model | Keep editable parameters, provenance, dependencies and target export checks |
| Fixed-view 3D | Compare static render value/cost against video and interaction before runtime selection |
| Dynamic visual conveys state | Bind to authoritative intent/result; preserve pause/quiet/failure conditions |
| Tool or license unavailable | Name the dependency, use suitable available work and scope the remaining result |
| Shared master changes | Re-export derivatives, update references and verify affected placements |

## Executed assurance

Deterministic tests check required files, current reference contracts, source
provenance, asset relationships, packaging and ordinary helper behavior. The
separate browser asset fixture exercises actual files, themes, CSS dimensions,
responsive source selection, fallback and motion control. The standard product
scenario and publication tests continue to run. CI results establish which checks
executed; image inspection supports only the captures actually opened.

The fixture reuses existing publication illustrations and an exact Lucide icon.
It is a QA workbench, not a proposed new product identity. Specialist 3D/font
production and independent agent effectiveness are outside its measured scope.
