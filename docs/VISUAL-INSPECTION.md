# 视觉观察：从整体感知到可执行的设计判断

UI Spec Studio 将 **Human-centered Visual Inspection & Perceptual Design Analysis**（面向人类视觉感知的观察与设计分析）作为 Visual Reasoning & Visual Inspection 的系统方法。Agent 从真实渲染和连续使用建立整体认识，深入空间、区域、组件与素材的关系，再用这些认识选择成熟实现、控制适配，并检查完整产品。

这一能力连接三个任务：**看见设计**，识别真实画面中的具体特征；**理解设计**，解释这些特征如何共同影响注意力、可读性、空间关系与产品气质；**运用设计**，决定继承什么、采用哪个实现、调整哪里，以及通过什么观察确认结果。

**完整观察 → 层次拆解 → 细节分析 → 关系理解 → 专业判断 → 资源选择与适配 → 实际呈现 → 再次观察。**

[产品体验对齐与主动探索](PRODUCT-ALIGNMENT.md)确定研究问题、发现实际观察对象，并将发现连接到资源和实现。视觉观察解释这些对象的品质。这条循环在原有 `init → iterate → finish` 中持续发生；`shape` 用于收敛重要方向，`audit` 可以检查任何已有范围。观察深度由当前设计问题、影响和不确定性决定。

## 从候选资源一直看到真实运行

研究成熟成果时，查看具体页面、组件变体、素材文件或演示状态。沿着相关线索实际播放、滚动、切换、展开与返回，补齐影响选择的组成、状态及其关系。组件的比例、字形、材质和反馈，背景的光影、视觉重心和运动范围，完整模板的信息层级与任务路径，都是选择依据。源码和说明帮助理解实现条件与复用方式。

嵌入演示需要明确观察归属：承载页面、播放器、演示中的应用界面、应用内作品分别提供不同参照。宣传视频中的艺术字可以启发作品内容；应用界面语言要从真实导航、工具栏、面板和反馈研究。页面源码能解释该页面及播放器，视频内应用的行为需要相应证据。

让品质目标与实际实现持续对应，分别观察四个对象：

| 对象 | 需要确认的设计价值 |
|---|---|
| 成熟参照中的相关部分 | 当前任务值得达到的成熟度，以及承载品质的设计关系 |
| 候选资源的原始演示 | 实现本身的细节、状态和动态完成度，以及依赖的展示条件 |
| 当前项目的局部试装 | 引入实际字体、内容、主题和交互后，关键品质是否仍然成立 |
| 整合后的页面与使用流程 | 多个组成是否形成统一表达，真实操作与业务结果是否保留预期体验 |

关键组成在扩大集成前完成局部试装，用长文字、多行输入、缺失图片或真实加载反馈等相关条件暴露差距。原始演示帮助判断资源能力，本地试装确认当前适用性，整体检查继续判断组合关系。常规实例可以继承同一体系在相同条件下已成立的证据。

例如，一个出色的动态背景进入文字密集的区域后，可能需要调整亮度、运动幅度或前景留白。资源本身不适合时重新选型，适配破坏关系时定位改动，内容暴露缺口时共同审阅内容和空间，组合冲突时协调主导设计语言。参照目标与任务不匹配时重新判断产品意图。实际证据决定处理层面；尚未达到的品质保留为明确差距。

## 从完整感知深入细节，再回到完整界面

从正常显示比例、实际视口和真实内容开始，先理解当前画面给人的产品印象，再决定哪里值得精读。长页面通过实际滚动理解展开节奏；缩小的整页图可以帮助定位区域，正常使用尺度下的文字、边界和视觉重量仍需对应画面确认。

| 观察尺度 | 值得研究的关系 | 应形成的设计认识 |
|---|---|---|
| 整体感知与第一印象 | 首先吸引注意的对象、主次信息、密度、秩序、产品气质 | 当前任务入口与整体表达是否符合产品定位；哪些区域值得深入 |
| 构图、比例与空间层级 | 区域占比、明暗和内容重量、留白分布、分组、对齐与阅读路径 | 各部分怎样共同形成平衡、层级和节奏；几何位置与光学重心是否协调 |
| 功能区域与内部组织 | 导航、输入区、卡片、面板或浮层的职责、信息顺序、操作入口与邻接关系 | 区域内部有哪些可继承的设计关系；其体量和位置怎样服务完整页面 |
| 组件、素材与精细制作 | 实际字形、轮廓、基线、图标比例、内外间距、边界、圆角、阴影与材质叠加 | 哪些细节共同形成清晰、自然的完成度；哪些调整会影响其他细节 |

按问题在这些尺度之间往返。局部裁切帮助辨认相邻关系，放大帮助定位轮廓与边界；随后回到原显示比例和周围内容，判断该细节在真实使用中是否重要。关键帧集合和缩略图适合比较构图或筛选片段，其单格尺寸限制细节判断。浏览器缩放还可能改变换行、布局和断点，应与单纯放大已捕获像素区分。重要比较保留视口、缩放、像素密度、字体、主题和内容条件；不同条件下的差异先确认来源，再决定是否属于设计问题。

调整后，检查该组件、相邻区域和完整画面：边界更清楚时，是否抢走了主要操作的注意；图标加大后，是否改变按钮重心；局部文字更疏朗时，是否挤压了主任务空间。随后在受影响的页面、状态和使用片段中确认同一关系。这样的往返使局部精修与整体品质相互约束。

## 用可组合的维度分析真实关系

以下维度帮助提出具体问题。根据设计对象与决策影响选择、组合和深入；它们分别解释不同关系，共同支持专业判断。

| 维度 | 实际观察对象 | 决策用途 |
|---|---|---|
| 视觉层级与注意力 | 显著性、对比面积、分组、阅读顺序、主次操作重量 | 判断当前焦点是否对应核心任务，信息能否按所需顺序被发现 |
| 空间构图与比例 | 分区、宽高、间距、留白、光学中心、密度与边界 | 判断区域是否平衡、成组且有节奏，内容增长后关系是否仍成立 |
| 字体与内容排版 | 字形、字号、字重、行高、字距、换行、段落及中英文混排 | 判断实际文字的可读性、层级和文字与容器的协调性 |
| 色彩与明暗组织 | 色相、明度、饱和度、色彩面积、前景背景关系与渐变 | 判断色彩如何组织焦点、状态与气质；检查主题中的层级变化 |
| 材质与表面表现 | 边框、阴影、透明度、模糊、纹理、反射、光源与叠加 | 判断深度是否连贯，表面能否与内容、背景和运动共同成立 |
| 形态与组件细节 | 轮廓、圆角、线条、图标、填充、基线和视觉重量 | 判断组件家族的精细协调，以及参数相同但观感不同的原因 |
| 素材与艺术表达 | 图像构图、裁切、清晰度、3D 材质、品牌符号及资产族 | 判断素材如何参与焦点与产品辨识，实际尺寸和放置是否保留其价值 |
| 交互状态与动态表现 | 悬停、聚焦、选择、展开、加载、轨迹、节奏与对象连续性 | 判断状态可辨性和时间中的空间关系，并明确需要的过程证据 |
| 系统一致性与产品特征 | 跨区域、页面的字体、密度、色彩、材质、图标和操作规律 | 判断差异是否来自页面职责，整体是否形成可辨识的产品语言 |

例如，Favicon 重点研究小尺寸轮廓、负形与重心，再放回标签页查看辨识；三栏工作区重点研究空间分配、内容密度、滚动和面板协同；一组素材同时研究单项艺术品质与整组裁切、色彩和线条关系。复杂动画进一步检查这些关系在完整运动范围内怎样变化。具体任务决定观察重点和足够的深度。

## 将“质感”解释为共同成立的设计关系

“精致”“高级”“有设计感”可以记录第一印象，后续判断需要说明感受来自哪里。设计意图明确时，焦点、分组、颜色和反馈相互支持；细节精确时，字形、基线、图标、边界和内部留白在正常尺寸下协调；语言统一时，不同形态共享可感知的比例、密度、材质与节奏；表现适当时，视觉强度符合品牌、内容和任务；真实使用稳定时，内容增长、加载、主题变化与连续操作仍能保留这些关系。

光学判断关注实际形态与背景。同样大小的图标可能因填充面积、开口和轮廓产生不同重量；几何居中也可能因文字密度、素材边界或周围留白显得偏移。尺寸与布局参数用于解释和实现，最终取舍回到实际画面确认。

对话入口、阅读页、数据工作台与品牌页都可以研究不同的视觉强度和密度。任务条件与明确的审美目标共同决定适当表达；复杂材质、丰富动效和克制表面分别作为候选手段。相近品质体现在当前任务需要的可读性、协调性、细节和状态表现，具体风格与参数由产品决定。

## 同时检查使用、表达与源设计保留

分别判断**体验成立性**与**表达完成度**：前者关注任务理解、阅读、操作与真实结果；后者关注承诺的艺术主题、素材品质、构图、细节和完整使用中的身份。专业产品同样可以采用鲜明表达。完成首次操作后，继续观察长内容、结果、导航、详情和跨页面过程，确认表达进入日常工作区域。实际用户的理解、记忆或偏好仍需要相应用户观察。

**Source Fidelity（源设计保真）**检查已经采用或批准的成果是否得到约定还原。对齐内容、视口、字体、素材及事件阶段，再用并列画面、结构或区域图像差异定位问题；记录容差、遮罩和有意改变。**Perceptual Quality（感知品质）**检查当前构图、光学平衡、排版、材质与动态关系。图像差异支持特定目标的实现诊断，艺术方向与成熟度依靠实际观看和产品条件判断。

修正具体的文字对比、运动范围或空间冲突后，同时复验使用与表达。已确认方向需要调整时，保留证据、影响和实际决定。艺术指导、视觉角色与复用之间的完整关系见[艺术指导指南](ART-DIRECTION.md)。

## 让感知判断进入资源选择与验证

重要观察建立以下联系：**视觉事实 → 感知效果 → 设计关系或原因假设 → 当前产品的适用判断 → 对应实现与适配 → 实际复验。**

例如，在一个输入区中实际看到边界较轻、表面仍与背景清楚分离，可以记录其查看尺度、背景及状态。专业解释可能是表面明度、细边界、文字重量和周围留白共同形成柔和层级；还不确定的因素，通过局部对照或样式检查继续验证。如果当前产品需要类似气质，就用这组关系比较成熟输入组件，在真实字体、内容、主题和容器中试装，观察聚焦、多行增长、附件与提交反馈，随后检查它对消息阅读空间和整页焦点的影响。所选资源、保留机制和适配结果由对应源码与实际画面说明。

这是一个条件性推理示例。一次观察支持它实际呈现的事实；感知效果是专业解释，具体实现原因可以仍是假设。真实使用者是否更容易理解、任务是否更快，需要相应用户观察。代码、样式和运行数据帮助检验原因、行为与工程条件，视觉判断持续以可见结果为依据。

比较资源时，同时判断资源自身的品质、当前任务的适用性、可继承关系的完整性，以及进入项目后的保留情况。让结论具体改变采用层级、候选选择、配置、适配或验证范围。原始演示、局部试装和完整页面各自提供必要证据；实际采用记录说明最终由哪个实现承担这些品质。

## 在空间、时间与旅程中观察

| 观察范围 | 主要判断 |
|---|---|
| 单个画面及局部细节 | 构图、焦点、比例、排版、素材、材质与状态可辨性 |
| 连续视觉片段 | 对象如何变化、反馈何时出现、运动如何影响周围内容 |
| 跨页面的任务旅程 | 共享导航、对象身份、阅读节奏、焦点、滚动与返回方式是否连贯 |

按实际支持条件纳入语言、主题、视口、真实内容和关键状态。页面可以因职责形成合理差异，同时通过统一的文字、组件和操作关系保持产品认知。

## Temporal Visual Inspection：以行为确定时间窗口

**时序视觉观察的基本对象，是具有明确时间关系、交互语义和状态变化的连续视觉片段。** 在参照、候选资源、本地试装和实际产品中比较对应任务与状态：触发前、用户动作、首次反馈、变化过程与稳定结果，必要时连接返回或恢复。容器、字体、主题和业务接入改变了过程时，重新检查受影响的空间与时间关系。

| 行为 | 有意义的观察窗口 | 可能需要扩展的条件 |
|---|---|---|
| 按钮反馈、展开、翻面等微交互 | 触发前到反馈、过渡与可读的结束状态 | 反向、中断、重复输入 |
| 循环背景、粒子或空间化动效 | 足以看到周期、节奏、变化范围和循环衔接 | 最大范围、峰值亮度、多种周期相遇；非周期效果的代表区间 |
| 异步计算或资源加载 | 发起前、等待、阶段反馈与有效结果或恢复状态 | 较早或较晚返回、失败、取消、新意图 |
| 滚动驱动变化 | 同时记录相关位置、方向、进入、停留和离开 | 反向浏览、局部滚动区、返回位置 |
| 导航、弹层与完整流程 | 出发、过渡、到达、继续及返回的相关片段 | 焦点、输入、选择、滚动与共享结构的保持 |

七个相关维度帮助解释这些片段：

| 维度 | 观察的问题 |
|---|---|
| 时间连续性（Temporal Continuity） | 开始、过渡与完成的先后关系是否自然、可理解 |
| 对象连续性（Object Continuity） | 形态、内容、位置与选择是否保留同一对象的身份 |
| 运动品质（Motion Quality） | 速度、缓动、轨迹、节奏和收尾是否符合动作含义 |
| 动态构图（Dynamic Composition） | 运动重心、文字、组件和素材是否保持清晰层级；光影、模糊、透明度与形态变化是否保留协调材质 |
| 状态与反馈一致性（State & Feedback Alignment） | 动画、文案、可用操作和实际结果是否描述同一状态 |
| 时序稳定性（Temporal Stability） | 加载、内容增长与连续操作时是否保留布局和操作位置 |
| 跨界面连续性（Cross-view Continuity） | 页面、弹层与流程之间是否保持身份、方向感和继续操作的上下文 |

在工具支持时，先以正常速度运行或播放理解整体，再通过暂停、重放、局部细节与相邻关键帧定位问题，最后回到正常速度检查完整关系。调整后重新查看相关区间与前后过程。已有演示提供作者选取的流程；主动操作记录补齐当前问题需要的反向、连续或异常条件。剪辑节奏与真实响应时间分别建立证据。

## 让证据支持它能够回答的问题

视频、有序帧、关键帧和实际操作各有用途。记录能重现重要判断的条件：来源与版本、视口和缩放、语言与主题、内容状态、触发动作、帧顺序和实际时间。比较时对齐有意义的事件，并说明真实加载时长或内容差异。

观察窗口跟随行为范围，采样密度跟随变化速度，分析深度跟随设计影响。连续采样需要能够分辨正在研究的变化。关键帧方便比较位置与状态；相邻画面帮助定位闪烁、遮挡或跳变；完整播放支持节奏判断。采样间隔、遗漏片段、录制缩放和捕获开销都限定观察范围。工具只能提供有序帧时，将结论限定在实际看到的序列，并保留仍需播放确认的部分。

受控时钟、逐帧定位与慢速播放用于分析顺序和中间状态。具备实现控制能力时，固定来源、视口、字体、素材、随机种子与时间轴可以支持重复的关键帧比较；记录实际控制机制和未被控制的部分。固定舞台的动态作品还需检查输出编码、可读停留、重置和循环首尾；关键帧集合与原尺寸帧帮助定位，完整播放判断相应时间范围内的叙事。

自然运行的节奏与流畅度需要对应条件下的观察，性能结论还需帧时间、长任务或其他相关运行测量。真实产品的用户与服务时序、演示中选定的流程、独立作品的作者时间各有验证边界。动画结束、界面出现成功样式和权威业务完成分别检查其实际含义。

最终记录区分**已经采集、实际查看或解析、证据足以支持的结论、已经操作验证、已经工程测量与已经获得用户批准**的内容。图像内容的分析可以支持对应帧的判断；流畅度、真实用户理解和业务完成各需匹配的证据。记录无需使用统一字段模板；已有项目文档只要能让人找到证据、理解判断并继续工作即可。

## 用观察形成可检查的设计决策

重要选型可以展示候选原始效果、局部试装和采用位置，说明实际保留的布局、状态或运动机制；重要迭代呈现相关画面或片段，解释调整目的与复验结果。内部机制显著变化后，当前实现需要承担相应品质验证。品牌气质或主要交互仍有明显分歧时，用可见方案支持用户确认。日常尺寸、排版和参数调整由 Agent 在既有方向下推进。

重要资料需要登录、官方客户端或授权导出时，可以在已有材料仍不足的具体问题上请求用户协助。集中说明访问对象、操作、相关状态或连续过程及其决策用途，随后继续实际观察和专业比较。收到文件建立材料可用性，允许研究与允许集成分别依据其使用条件。

观察应带来具体价值：发现可采用的成熟实现、确认适用性、识别问题、改变决策或确认修正。完整工作方式是：

**Observe → Interpret → Evaluate → Decide → Implement → Inspect → Refine**  
**实际观察 → 专业理解 → 质量评估 → 设计决策 → 工程实现 → 结果检查 → 持续优化。**

这一方法同时适用于应用 UI、README、图表、字体、图标、视觉素材与动态作品。具体媒介决定查看方式，实际使用目标决定品质判断。

关键视觉关系已经理解、候选具备相应品质、适配路径清楚且现有证据足以支持当前决定时，推进实现。后续观察集中于尚能改变选择、消除重要不确定性或验证修改影响的问题。新增内容、状态和使用条件改变了原有关系时，再回到相应尺度深入研究。观察次数和分析维度的数量描述工作范围，完成依据是实际设计问题得到足够回答。
