# Coordinator visual observations

These are coordinator observations of ten original PNGs, opened through the
retained actual image-tool requests and responses in this directory. They are
separate from the independent reviewer and do not approve release. The images
are anonymous delivery copies whose hashes and original paths are in the
existing `coordination/blind-materials-Pxx.json` records.

- T3 final runtime (P02): the desktop index retains the Paper family, serif
  reading hierarchy, aligned sheet/margin and native sidebar. The 390px English
  and Chinese/dark reading views retain readable text and native note controls.
  Capture 009 is explicitly the repaired ledger's **right-panned state**, so its
  partially hidden first column is not itself evidence of inaccessible content.
  A static frame does not prove panning operability or keyboard table access.
- T2 final runtime (P04): the observed desktop and narrow dark conversation views
  retain a clear reading area, distinct composer and source-family structure.
  These static images do not establish streaming follow behavior, focus recovery,
  filename disclosure or a natural-time motion result.
- T1 final runtime (P05): the desktop failed-save state visibly preserves a
  retriable error in the form context. Narrow Chinese long-value fields wrap
  across several lines inside the same settings family. This view alone does
  not certify persisted values or all page navigation.
- T4 final runtime (P18): the desktop dark save-failure notification retains its
  explicit retry action and the settings context. The narrow invalid-input state
  shows field-specific messages and intact form hierarchy. Input panning, focus
  recovery and retry snapshot semantics require the behavioral evidence rather
  than inference from these pixels.

No screenshot count, assertion count, child count or familiar source family is
treated as a universal quality result. The independent reviewer must inspect all
comparators and determine its own final-runtime disposition.
