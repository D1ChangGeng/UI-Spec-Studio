UI Spec Studio v1.20.0 — experiment event records

This is a text-only supplementary record of Playwright action metadata.
INDEX.json links each derived event stream to its original archive and raw run SHA-256.
The original event line number and SHA-256 are retained for source comparison.
Pixels, screencast frames, DOM snapshots, network records, arguments and result payloads are excluded.
The archive cannot replay or replace a full browser trace. Public product snapshots and reviewed evidence remain with the release repository.
Recorded automation timestamps are not model execution times or application performance measurements.
The current file may be updated as further registered cells finish; each saved version identifies its completed subset.
