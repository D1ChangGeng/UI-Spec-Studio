! Paper

An editorial theme for TiddlyWiki. Cream paper, warm ink, a red margin rule.

It does not depend on Vanilla and inherits no rule from it. It does depend on Paper is self-contained: it carries the sliding layout engine and the structural CSS itself, and depends on no other theme. Its stylesheets are numbered because their order is load-bearing — `1-layout` sets the geometry, `2-structure` the rules the core markup needs, `3-surface` this theme's material, and the plugin sheets come last. TiddlyWiki concatenates stylesheets in title order, so the numbers are the only thing keeping a theme's overrides after the structure they override.

!! The sliding layout

Vanilla changes the sidebar and story-river layout by swapping CSS rules — the `if-no-sidebar` and `if-fluid-fixed` macros wrap CSS text in a reveal widget, so toggling `$:/state/sidebar` rewrites the stylesheet. A stylesheet edit applies in a single frame with no start value to interpolate from, which is why the layout jumps.

Paper emits every rule unconditionally and animates one registered custom property instead:

```
@property --btc-open { syntax: "<number>"; inherits: true; initial-value: 1; }
```

State reaches CSS as classes on the page container, contributed through the core's `$:/tags/ClassFilters/PageTemplate` hook. One scalar, one transition, both layouts, both text directions.

!! Compatibility shim

The Vanilla-namespace shim now lives in Paper ships all three halves of it — `$:/themes/tiddlywiki/vanilla/metrics/`, `/options/` and `/settings/` — since it no longer shares them with anything.

This is deliberate, and it is a workaround rather than a design choice. The core and several bundled plugins read Vanilla's metric and setting paths directly regardless of which theme is active — `$:/core/stylesheets/custom-properties` builds every `--tp-*` property from them, and the menubar plugin computes its media-query breakpoints from `$:/themes/tiddlywiki/vanilla/metrics/sidebarbreakpoint`. With no Vanilla installed those lookups return empty, which produces invalid CSS such as `@media (max-width: )` and silently drops the affected rules.

These shadow tiddlers only exist while Paper is the active theme, so they cannot affect a wiki that has switched back to Vanilla.

> ''Note:'' the shim holds static values. Changing a metric in Paper's Control Panel tab does //not// update the Vanilla-namespace copy. If you change the sidebar breakpoint and use the menubar plugin, update `$:/themes/tiddlywiki/vanilla/metrics/sidebarbreakpoint` to match.

The real fix belongs in the core: those lookups should resolve against the active theme rather than a hard-coded one.
