# Takeover evidence helpers

These separate copies add an explicit evidence-directory name for an actual replacement run. They do not change the frozen task, method, role, prompt, candidate fingerprint or release checks. `UI_STUDY_RUN_NAME` selects the snapshot/blinding directory; `run_directory_name` selects the same directory in the indexing configuration. The cell ID remains the registered ID.

The host has made some deleted/moved files visible again after successful in-command checks, including a redundant unconfirmed T4 snapshot. Keeping a different output directory prevents confusing old bytes with a newly completed product. Original attempts remain retained, and their files do not establish completed participation without actual terminal notifications.

Only coordinator evidence packaging is changed here. The acceptance validator under tools/ remains frozen. Helpers retain exact original bytes and verify reconstructed workspaces.
