# Continue Leafnote on the same implementation

density for longer Chinese and English notes: clearer title/body/metadata roles,
comfortable reading measure and labels that stay understandable at narrow width.

unsaved draft must survive a density, theme or language change. Recheck the existing
create, save, search, reopen and delete tasks with long content. Resolve regressions
