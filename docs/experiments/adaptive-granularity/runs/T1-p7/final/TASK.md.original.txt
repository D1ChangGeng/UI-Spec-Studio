# Leafnote: a clear daily notebook workspace

Use the supplied ui-spec Skill to improve the existing application in `app/`.
This is a browser-local product demonstration for a small research team. Keep its
honest local-storage boundary; do not add a backend or imply cloud synchronization.

Make the conventional workspace feel complete for the daily task of creating,
saving, finding and reopening research notes. The current one-note editor is a
starting point. Support a collection of notes with title/context, a search field,
selection and return to editing. Preserve Chinese/English, light/dark, keyboard
operation, draft safety and meaningful storage-failure feedback. Deleting a note
must identify the note and allow cancellation. Existing saved content should remain
recoverable. Use realistic short and long synthetic content.

The desired design is calm, editorial and precise: a useful collection/editor
relationship, confident type, readable spacing and purposeful surface hierarchy.
Develop the same product using suitable mature resources and actual visual
research. Show the implemented result and consequential choices in a normal user
delivery. Keep internal research commentary outside the product's main interface.
It should work at 1440×900 and 390×844. Do the work and inspect the real result.
Record remaining limitations accurately if some part needs subsequent work.
