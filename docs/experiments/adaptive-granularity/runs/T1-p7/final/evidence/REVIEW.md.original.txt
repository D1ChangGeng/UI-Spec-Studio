# Review record

## Environment and boundary

Local HTTP application at `http://localhost:8777`, Playwright Python, supplied Chromium headless shell 143.0.7499.4, device scale factor 1, viewports 1440×900 and 390×844. Real browser `localStorage` was exercised. Native exceptions and authored delays were injected explicitly. This was a desktop browser with resized viewports, not a physical phone. No deployment or external account actions occurred.

## Executed checks

`run-2/results.json` records **36 passing assertions** covering creation, update, title/context/body data, body search, selection/reopening, empty search, draft switching/reload, actual collection persistence, keyboard saving, named deletion, safe initial focus, Escape cancellation, failed deletion, successful deletion, failed save and retry, a delayed snapshot with newer edits, JSON export, eight viewport/locale/theme overflow checks, console errors, legacy migration, malformed-data protection, native quota errors and recovery.

The final follow-up (`final/checks.json`) records four passes and one failed read-retry case. **The failed case is not relabeled.** Its repair is independently checked in `final/read-recheck.json`: editing after a read error, retrying, preserving the draft, writing it durably, and re-enabling Save all pass.

`final/safety-checks.json` records four further passes: blank-title error/focus, reduced-motion control styling, a visible mobile malformed-data explanation with retry, and successful collection-side recovery. Other-tab mutation detection and draft-preserving recovery passed in the follow-up. This is not atomic multi-tab merge testing.

## Limits

No actual screen-reader playback, real mobile keyboard, Safari/Firefox run, large-collection performance study, or user acceptance session was conducted. The capture sequence is sampled static evidence; it does not establish continuous frame-rate or animation performance. Long-note body content scrolls inside the native textarea. The pinned browser predates the newest non-scrollable modal-backdrop containment behavior, so full backdrop scroll isolation is a progressive enhancement.

Export is available; import is not. Cross-tab collection changes are detected, but read/compare/write is not a transaction and concurrent draft maps are not merged. Local storage is not a durable cloud backup. Pico 2.1.1 is pinned and locally vendored; its upstream now reports it is unmaintained.
