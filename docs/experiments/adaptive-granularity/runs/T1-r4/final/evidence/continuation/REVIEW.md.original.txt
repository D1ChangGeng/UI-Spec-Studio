## Decision and reuse
Preserve the accepted collection/editor relationship and its adopted Bootstrap 5.3.8 list/form/button foundation. Use its native select styling for a visible Density preference, available on both collection and editor views. Keep the existing local Inter and serif/CJK fallback families. No new font or framework is required.

Comfortable uses larger body type and more generous line/section spacing; Compact reduces repeated spacing and type slightly while preserving metadata at 11–12px and readable labels. The editor's width follows a 66ch measure plus padding. English labels use natural case; Chinese labels avoid artificial tracking. Chinese title line-height is increased for mixed punctuation and longer titles. On mobile the preference receives its own header row so the label and selected value remain explicit.

Density is a shared data-density value and a field in leafnote-preferences. It does not select a different note or write note content. Preference write failures are reported. Keyboard shortcuts ignore focused selects.

The two densities retain the same hierarchy: title, labeled prose, then smaller metadata. Compact visibly exposes more collection rows and more prose without hiding labels. The mobile density row fits at 390px and the save area remains reachable. Existing safe deletion and draft behavior were re-exercised using long content.
