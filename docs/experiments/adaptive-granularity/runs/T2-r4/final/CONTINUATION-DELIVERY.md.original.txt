# Sources are now available while the answer arrives

Meridian now connects citations to individual answer paragraphs before the long response finishes. Open an inline citation to read its source while later paragraphs continue arriving. The cited paragraph is highlighted in the conversation and repeated in the reading room, so the connection remains visible.

**[Open Meridian locally](http://127.0.0.1:8844/app/)**

## Try the connected experience

1. Open **Demo**, select **A longer answer**, and ask one of the starter questions.
2. Open the first numbered citation when it appears beside its paragraph. You do not need to wait for the answer to finish.
3. Read the source while the answer continues. On desktop, the composer remains available; grow a follow-up draft or scroll back in the conversation.
4. Use **Stop response** in the source reader. The same control becomes **Try again**, which restarts the answer while preserving the source context and draft. A long response stays long on retry.
5. Choose **Back to answer**, close the panel, or press Escape. Return resolves the relevant citation even after retry has replaced the answer. **Latest response** remains the explicit route to the unfolding end.

At 390×844, the source opens as a focused native dialog. Stop/retry controls are included inside it, and Back to answer stays visible when the source is scrolled. The full answer remains behind the dialog and resumes as the same thread when it closes.

## What changed and why

The earlier footer sources appeared only after completion. Three inline citation controls now arrive with their associated paragraphs. Each carries stable answer/paragraph identity into the existing source reader. This lets the source context survive an answer being stopped or regenerated, rather than depending on a button that may have been replaced.

Opening a source suspends automatic following of new output. The conversation keeps its reading point while the source is open, including when the desktop composer grows. The source panel reports the answer's actual local state—arriving, stopped or ready—and its controls operate on that answer. This is still a synthetic local demonstration; the sources are not retrieved publications.

The warm surfaces, editorial typography and quiet action hierarchy continue through the connected state. The cited paragraph and its source context use the same restrained tint. The return control becomes a persistent bar when reading farther down a source.

## Remaining boundaries

The paragraph/source associations are authored for the deterministic fixture. There is no live retrieval, factual verification or arbitrary citation parsing. A retry temporarily retains the cited text in the source view while the corresponding answer paragraph is regenerated; if that paragraph is not yet available on return, the composer is the safe focus target.

Physical mobile keyboard behavior, Safari/Firefox, screen-reader operation and very large research threads remain unverified. Compact mode deliberately focuses on the source; composing resumes when the dialog closes. The current evidence supports the requested local journey, not a production research service or owner design approval.

No deployment or publication occurred. The same static app remains in `app/`, and the local server remains on port 8844.
