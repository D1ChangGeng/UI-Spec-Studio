# Continue Meridian with source reading

Develop the same workspace so a citation opens a readable source panel while a long
answer is still arriving. The cited paragraph must be identifiable; the person
must be able to close the panel and continue from the same conversation and draft.
At narrow width use a suitable focused source view with a clear return. Preserve
user control of scrolling: scrolling back to read should not be overridden by new
output; returning to the latest answer should be easy. Exercise opening/closing,
composer growth, stopping and retrying while the panel is present. Retain useful
visual choices from the first delivery and refine them when the combined experience
requires it. Show the actual result, affected checks and any remaining gaps.
