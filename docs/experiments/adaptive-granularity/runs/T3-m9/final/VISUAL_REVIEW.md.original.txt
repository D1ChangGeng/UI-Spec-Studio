2. `run-01.log`: fault-injection harness returned a function expression that Playwright invoked. The harness was fixed; this was not an application save failure. Earlier captures are in `run01/`.
3. `run-02.log`: an actual reduced-motion return button was intercepted by an inactive layer. Flattened reduced-mode faces and explicit inactive hit-area removal repaired that part. Earlier captures are in `run02/`.

Reduced mode now removes those button effects. `reduced-probe-02.log` records the successful pointer path and committed record. The final full suite in `run-04.log` passed all 43 assertions.
5. Visual repairs: corrected the missing mobile title space; adjusted the narrow heading and card height; replaced a visibly hollow oval shadow with a filled, blurred cast shadow.

## Judgment and open scope

The current result presents one stable note and a readable research question, with a coherent paper treatment in both themes. Its center pivot supports that relationship more directly than the examined lateral alternative. These are agent visual judgments, not owner acceptance or user-study findings.

The natural-time sequence is sampled rather than continuously played back. Frame delivery, real touch hardware, mobile software keyboard behavior, Safari, Firefox, screen-reader announcements, forced colors and zoom/reflow beyond the two requested viewports remain unverified. Functional tests do not promote those dimensions to passes.
