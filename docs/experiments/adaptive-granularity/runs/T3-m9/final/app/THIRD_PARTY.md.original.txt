# Resource adoption

The scene / object / two faces structure and centered card-flip mechanism follow David DeSandro's **Intro to CSS 3D transforms — Card Flip**:
https://3dtransforms.desandro.com/card-flip

The source explicitly licenses example code under MIT. Its alternative slide-flip was compared as a motion reference. Fieldnote retains the existing vanilla application and adapts the centered mechanism, two hidden reverse faces, inherited perspective and reversible CSS transition. The application-specific save authority, focus handling, paper treatment, composition and bilingual copy are maintained here.

## Collection navigation

The collection uses the browser's same-document View Transition API as a progressive enhancement for whole-view navigation. The current API contract and fallback were checked against MDN: https://developer.mozilla.org/en-US/docs/Web/API/Document/startViewTransition . This is a platform reference, not an imported visual component. Reduced motion or a missing API performs the prepared update immediately. Project-owned code manages stable record IDs, per-note drafts, navigation cancellation and focus/scroll restoration.
