# Source and adaptation notes

## Card motion

David DeSandro, Intro to CSS 3D transforms, Card Flip:
https://3dtransforms.desandro.com/card-flip

The official page states that all example code is MIT-licensed and links to
https://desandro.mit-license.org/ . Its written explanations are CC-BY.

Retained technique: a fixed scene carrying perspective, one transformed object with preserve-3d, two equal faces with backface visibility hidden, and a center-origin rotation. The original application already contained this family. This work adopts/refines that mechanism and provides a new scene composition, shading, duration, input semantics and outcome-driven state adapter. No third-party runtime dependency or image/font redistribution is included.

The live center-pivot and slide-flip examples were operated in the isolated test browser. Source frames and the retrieved HTML are in evidence/. The source example is a motion primitive, not a full product layout. Its maturity is not claimed for the newly authored state/focus code.

## Platform guidance

The supplied GoogleChrome modern-web-guidance material was read for form sizing and motion fallbacks. Bounded internal scrolling was selected for the card because growing the card would conflict with its stable footprint.

W3C WAI animation-from-interactions guidance informed the alternate motion mode:
https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html

No formal WCAG conformance claim is made.
