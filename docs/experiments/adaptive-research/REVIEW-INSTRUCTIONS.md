# Independent review instructions

Examine actual anonymous runnable products under matched conditions. Do not identify conditions or models before the judgments are frozen. Compare whole composition at intended scale, relevant detail, real populated states and meaningful continuous episodes. Identify supported strengths and failures instead of inventing an aesthetic score or universal winner.

A separate process auditor checks original source identities, real browsing/viewing, native child sessions, pivotal main-Agent inspection, exact adoption, unauthorized design changes, shared-GUI interference, code conflicts and actually observed costs. Record what is unavailable. Reviewer independence, observable execution, empirical effect and user acceptance are separate facts.

Keep all compared outputs immutable. Later repairs belong to a separately named continuation. References, component demos, project trials and final products must not be substituted for one another. A frozen image exists independently of whether anyone actually viewed it. Publish only evidence whose privacy and reuse rights have been reviewed.
