# Resource starting points

Exact Magic UI sources are included with their MIT license and commit identities in sources.json. Official demonstrations: https://magicui.design/docs/components/magic-card and https://magicui.design/docs/components/shine-border . Other sources may be studied if useful; this is an open choice, not a required list.

MagicCard offers pointer-responsive surface and border gradients (and an orb variant). ShineBorder is a time-driven edge treatment. Read the actual source/props, inspect the chosen demonstration and judge fit in this product. The source files are unmodified. You may build a local harness to run them; label that harness as a local source rendering, not the official website. Required dependencies are already available, and app/src/lib/utils.js supplies the cn utility. Keep the copyright/license with adopted source.
