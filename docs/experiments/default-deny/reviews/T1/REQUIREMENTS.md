# Index — an editorial collection workspace

Use the supplied ui-spec Skill to implement the collection workspace in app/.
The starter has a React/Vite toolchain and representative collection data.
Build a useful browser-local product for finding, opening and saving research
collections. Support text search, a saved-only filter, saving/unsaving cards with
persistence, and a readable detail view with a clear return to the collection.
Preserve the search/filter and reading context when returning. Retain a usable
outcome and accurate feedback if a storage write fails.

Give it an editorial identity: near-black graphite surfaces, warm off-white text,
clear display/body type hierarchy and a restrained warm accent. Cards should have
a softly pointer-responsive surface or edge treatment, with readable content and
considered keyboard and reduced-motion behavior. Keep the header, controls,
collection and detail coherent as a working product. Long titles and narrow screens
matter as much as the initial empty state.

The resources/ directory supplies licensed source examples, exact versions and
official demonstration links. They are optional research leads, not a prescribed
supplier, a quality certification or a complete design. Other sources may be used.
Choose the scope and implementation that this product needs. Implement and inspect
the actual result at 1440×900 and 390×844.

Use Chinese for outward explanations. Keep useful evidence and source notes in
this workspace, and state the actual result, remaining gaps and how to run it.
