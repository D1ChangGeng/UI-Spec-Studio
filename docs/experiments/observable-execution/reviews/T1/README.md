# T1 independent product review archive

The complete original report is [review.md](review.md). Its wording and all retained original files are byte-identical to the reviewer output. This is independent Agent review, with the actual viewing and interaction limits stated in that report.

The [archive index](archive-index.json) records every original file's SHA-256, its direct path or ZIP member, and the anonymous product source comparison. The [study mapping](../../review-input-plan.json) was withheld from the reviewer until product observations had been recorded.

## Evidence access

Reports, scripts, JSON measurements, failure records and directly linked or gallery captures are readable in this folder. The remaining original captures are preserved here:

- [supplementary-evidence.zip](supplementary-evidence.zip) — 6,251,488 bytes, 86 original files.

Extract each supplementary ZIP into this directory to restore its original relative paths alongside the loose files. Each ZIP is independently extractable. The check scripts retain their original local environment paths and ports; consult `ENVIRONMENT.md` before replaying them.

## Preservation boundary

The archive retains 127 original review files (8,173,606 source bytes). Product copies, dependencies and generated caches are excluded. All 49 authored anonymous product files, including the original starter when present, were compared with the corresponding frozen run snapshot and matched. The product archives remain under the study's `runs/` directories.

Captured and actually viewed images remain separately identified in the original reviewer manifest. The [gallery](../../GALLERY.md) shows selected original captures without compositing or image edits; it does not imply that all archived captures were viewed or establish a quality ranking.
