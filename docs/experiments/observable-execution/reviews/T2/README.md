# T2 independent product review archive

The complete [reading copy](review.md) contains the original review with repository-relative evidence links. The [unaltered original report](review.original.md.txt) preserves every source byte, including its original sandbox URLs. Only that same-directory URL prefix was removed in the reading copy; wording, measurements and conclusions are unchanged. Both hashes and the exact transformation are recorded in the [archive index](archive-index.json).

This is independent Agent review of the original frozen L6, N3 and P8 products, with the actual viewing and interaction limits stated in the report. No captures from a later continuation or repair are included. The [study mapping](../../review-input-plan.json) was withheld from the reviewer until product observations had been recorded.

## Evidence access

Original perception records, failure notes, scripts, JSON measurements, logs and directly linked or gallery captures are readable in this folder. The remaining original captures are preserved here:

- [supplementary-evidence.zip](supplementary-evidence.zip) — 6,467,824 bytes, 54 original files.

Extract each supplementary ZIP into this directory to restore the original relative capture paths alongside the loose files. Each ZIP is independently extractable. The scripts retain their original local environment paths and ports; consult [ENVIRONMENT.md](ENVIRONMENT.md) before replaying them.

## Preservation boundary

The archive retains 105 original review files (12,097,151 source bytes). Product copies, dependencies and generated caches are excluded. All 12 authored anonymous product files were compared with the corresponding frozen final run snapshot before and after archival and matched. The product archives remain under the study's `runs/` directories.

The index lists every retained original file's SHA-256 and its direct path or ZIP member. The [gallery](../../GALLERY.md) uses nine original 1440×900 desktop captures cited in the review and reopened during archival; no image has been composited or edited. The reviewer did not produce an exhaustive per-image viewing manifest. Preserving all captures does not imply that all of them were visually inspected.

The review retains the L6/P8 early focus mismatch and original failed checks. Headless screenshots, keyboard actions and state traces support the specified observations; there was no natural-speed motion playback or screen-reader session. The record does not establish a quality ranking, cross-browser coverage or all language/theme/state permutations. An initial failed-check console transcript that was not captured cannot be reconstructed; the original failure account states that gap.
