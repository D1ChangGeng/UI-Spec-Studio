# 初次实看记录（源码诊断之前）

2026-10-30。仅先读 TASK.md、ENVIRONMENT.md，并列出 app 文件名；未读产品源码、README、作者说明、Skill 条件或方法映射。以指定 Chromium 实际打开三者，在 1440×900 与 390×844 实际点击翻面、已存笔记、返回编辑，手机切换中文和深色。截图在 captures/，原始可见 UI/焦点数据在 initial-ui.json 与 operated-ui.json。截图中的 saved-dialog 实际为整页“已存笔记”视图，文件名沿用初始脚本命名，不代表模态框。

## L6

- 浅米色背景、暗绿正文、白纸卡片、细描边和底部薄层边缘组成较安静的笔记桌面。封面先读问题，底部方格与轨道成为小插图；右侧标题与输入框层级明白。
- 1440×900 的左右两栏比例平衡，正反停稳后卡片位置与外形保持相同；背面沿用纸色、角半径和底部厚度，阅读内容取代插图，没有换成另一类容器的感觉。
- 手机首屏最紧凑：英文主标题单行，问题三行，输入框约三行高；保存按钮在 844px 首屏内。不是所有长内容可见，但初始任务路径清楚。
- 中文深色下正文和纸面层次仍可辨认。背面英文正文呈衬线风格，文字密度比右侧输入区稍高。

## N3

- 正面上半部的绿色方格与轨道图最有封面感；下半部问题清晰，编号、图注和题材标签构成相对完整的封面层级。背面去掉插图、保留纸张轮廓与重量，文本区宽松。
- 桌面卡片比 L6 更高、下投影更强；手机题目只占两行，而页首标题占两行。保存按钮位于首屏底部附近。
- 翻面控件有文字与方向箭头，背面状态也能直接读出返回问题。中文深色下标题与文本对比明显；静态实看未见重叠或裁切。

## P8

- 纸张、页码、细横线、右下角小箭头以及带横线的输入区，围绕写笔记形成最一致的文具语汇。轨道缩为右上小印记，主体视觉由问题文字承担。
- 桌面正反面共享编号、分隔线和纸张外形，背面文本换成易读的无衬线正文。阴影较宽较深，纸张与页面的距离感更明显。
- 手机页首标题和卡片之间留白较多，输入框更高；英文初始界面的保存按钮位于 844px 折线以下，需要向下滚动。此处是信息密度/到达成本的差异，尚不足以判作功能失败。
- 中文深色的纸面是绿色渐层，与背景保持层次。P8 翻面按钮的视觉箭头可能参与可访问名称，造成精确名称的测试脚本定位失败；改为匹配可见文字后实际点击成功。
