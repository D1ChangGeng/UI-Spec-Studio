# Index — an editorial collection workspace

Use the supplied ui-spec Skill to implement the collection workspace in app/.
The starter has a React/Vite toolchain and representative collection data.
Build a useful local product for finding, opening and saving research collections.
Support text search, a saved-only filter, saving/unsaving cards with persistence,
and a readable detail view with a clear return to the collection. Preserve the
search/filter and reading context when returning. Keep the local-only boundary
honest and retain a usable outcome if a storage write fails.

Give the product a distinctive editorial identity: near-black graphite surfaces,
warm off-white text, deliberate display/body type hierarchy, and a restrained warm
accent. The collection cards are consequential visual objects. Their surface and
edge illumination should respond softly to pointer position, keep text dominant,
and feel equally considered when operated with a keyboard or reduced motion.
The whole composition should remain a working collection tool with a coherent
header, search/filter, cards and reading detail, rather than a promotional hero.

The resources/ directory contains exact licensed source candidates and their
official demo links. They are starting points, not a prescribed supplier or final
design. Select and adapt suitable mature work and make the actual product feel
complete at 1440×900 and 390×844, including short and long collection titles.
Implement, inspect and deliver the actual result.

workspace as useful for continuation. State the actual result and limitations.
