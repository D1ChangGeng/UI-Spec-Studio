# UI Spec Studio 1.1.0

A complete professional context for agent-led UI design, small reviewable
increments and real product integration.

## Working model

- Six common references are read together before substantive UI work.
- Shape is optional and resolves material product, aesthetic or technical uncertainty.
- Iterate owns scope selection, component research, implementation, inspection and review.
- Finish reconciles approved experience with real authority, data and persistence,
  then verifies both design and business behavior.
- Skill reading contracts and host context/runtime responsibilities are explicit.

## Distribution

Install with `npx skills add D1ChangGeng/UI-Spec-Studio --skill ui-spec`.
For this version, use the repository tree at `v1.1.0`.

Assets contain the complete source bundle, standalone skill, per-file inventory
and SHA-256 checksums. CI gates cover deterministic tooling tests, package
integrity and standard installer behavior. The publish step reads downloaded
assets back before making the release public.

## Assurance scope

The model and writing were reviewed file by file and through logical scenarios.
Engineering tests establish package/tool behavior. Real browser outcomes,
host-agent understanding and comparative design quality require their own
observations in actual product tasks. See `docs/EVALUATION.md` and the Actions run
for the exact validation attached to this source revision.
