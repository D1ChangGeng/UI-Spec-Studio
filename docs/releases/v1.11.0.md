# UI Spec Studio 1.11.0

Art direction and expressive contrast now connect the desired visual identity to
mature implementations, role-based systems, specialist asset work and semantic
motion. Explicit aesthetic goals remain delivery requirements in professional
software as well as creative surfaces.

## Design behavior

- Research functional experience, cross-domain expression and actual implementation
  sources together. Compare material differences through similarly resolved previews.
- Preserve familiar task relationships while allowing independent composition,
  type, shape, material and motion. Check the language in populated core work.
- Convert the chosen direction into reusable roles and purposeful exceptions.
  Trial defining material beside real controls/content before broad integration.
- Resolve concrete usability or runtime failures while preserving the confirmed
  direction; make necessary target changes explicit.

## Verification

Assess experience validity and expressive completion independently. Source fidelity
protects selected or approved work; perceptual quality concerns the actual rendered
result. Image differences remain diagnostics with declared conditions.

Working products, representative demonstrations and authored visual output need
their own evidence. Deterministic timelines support repeatable phases and loop
comparison; actual interaction, natural-time playback and performance retain their
respective boundaries. The [review](../REVIEW-v1.11.0.md) records executed application
and engineering evidence.

The eight common references, their existing size budget, optional records, mature
implementation default and `init → iterate → finish` workflow remain. No new
required runtime dependency, workflow phase or fixed aesthetic score is added.
