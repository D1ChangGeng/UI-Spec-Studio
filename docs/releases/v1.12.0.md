# UI Spec Studio 1.12.0

Evidence-Driven Deep Visual Exploration makes the depth, diversity and
credibility of design research part of the decision process. Important
visual choices should draw confidence from actually inspected work,
meaningful comparisons and demonstrated adoption—not model familiarity,
a first attractive match or fixed search counts.

## Behavior

- Allocate exploration using design impact, specific uncertainty and
  potential upside. Permit extensive, multi-round research for defining
  elements and direct adaptation for well-supported routine ones.
- Study target experience and adoptable implementation together, following
  actual clues from whole products into type, visual assets, motion and source.
- Actively challenge early favorites with materially distinct candidates
  under comparable conditions. Separate observed facts, inferred qualities,
  source mechanisms, local trials and final integrated results.
- Assess evidence through breadth, depth, temporal coverage, relevance
  and reliability. Use authorized alternatives or focused user assistance
  when critical media is inaccessible.
- Converge by decision maturity and the expected value of more research.
  Reopen a candidate when local or integrated work reveals a significant
  difference. Keep decision records short and useful.

## Assurance boundary

The [guide](../DEEP-VISUAL-EXPLORATION.md) and common runtime references
define the method; [version review](../REVIEW-v1.12.0.md) separates mechanical
checks from observed agent behavior and product-quality evidence. Structural
tests do not establish that the skill actually causes better designs. No
additional common reference, installed runtime dependency, fixed source
quota, aesthetic score or mandatory workflow phase is introduced.
