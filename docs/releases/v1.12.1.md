# UI Spec Studio 1.12.1

This patch includes the runner's observed `/etc/apt/apt-mirrors.txt` in the Ubuntu
mirror selection step used by both browser jobs. The change covers the mirrorlist
that the runner actually read during browser dependency installation.

## Patch scope

The existing URI replacement now checks that mirrorlist alongside direct APT
source files. Package verification, job timeouts, workflow permissions, pinned
Actions, scenario assertions and release dependencies retain their existing
configuration.

The design instructions and runtime references remain those of 1.12.0. Only the
Skill's version metadata advances; current installation links identify 1.12.1.
The [experience research guide](https://github.com/D1ChangGeng/UI-Spec-Studio/blob/v1.12.1/docs/EXPERIENCE-RESEARCH.md)
explains the design method.

## Evidence

The 1.12.0 workflow completed all eight jobs and its published-tag installation
check. Its logs still showed actual package requests to the Azure mirror, so that
successful run did not establish that the first URI replacement changed the
download host or improved transfer speed.

The [1.12.0 review](https://github.com/D1ChangGeng/UI-Spec-Studio/blob/v1.12.0/docs/REVIEW-v1.12.0.md)
retains the original design and independent-application evidence against its
frozen inputs. The [1.12.1 patch review](https://github.com/D1ChangGeng/UI-Spec-Studio/blob/v1.12.1/docs/REVIEW-v1.12.1.md)
records the mirrorlist correction, checks and actual publication observations.
The new workflow's effective package host must be established from its runtime
logs; a successful replacement step alone does not establish that result.
