# UI Spec Studio 1.14.0 — Multiscale design evidence and action

Connect intended experience, actual research, professional judgment, mature
resource adoption and real-use checks through a multiscale design evidence map.
**Publication timeline:** at the original v1.14.0 tag, three-arm experiments were prepared but not yet executed. **Post-release (2026-10-28 JST):** 18 real Agent runs and 12 locked anonymous comparisons are now complete. The product owner reports consistently better human-perceived UI aesthetics, smoother spatial experience and more preferred colors in the structure + action arm, and accepts this direction as a positive v1.14.0 improvement. Anonymous Agent preference remains mixed and is faithfully preserved; no all-model causal effect is claimed.

## Design method

- Connect L0–L5 scales with state/time, conditions, dependencies and provenance.
- Challenge initial coverage through user tasks and real product discoveries.
- Use seven evidence-linked relations for consequential design decisions.
- Keep research, adoption, verification and approval as separate scoped facts.
- Let important gaps drive actual next actions and limit only dependent commitments.
- Extend existing records with Overview, Detail and Execution views; serialization
  and helper use remain optional, with depth proportional to design impact.
- Preserve all previous runtime knowledge and the eight-reference reading contract.

## Tools and evidence

A standard-library, read-only checker validates declarations and local references;
it does not inspect pixels, authenticate research or approve visual quality.
The experiment preparation kit freezes the exact v1.13 baseline, three isolated
instruction arms and six matched task prompts without claiming executed runs.

## Post-release empirical findings (2026-10-28)

- **Production identity confirmed:** the immutable v1.14.0 Skill contains both the multiscale evidence-map and evidence-to-action methods. It is not the baseline or structure-only arm. The study's `structure-action` treatment is a 31-file instruction ablation, not a byte-identical copy of the 34-file production distribution.
- **Execution:** 18 independent runs (six tasks × three arms), all completed; task-specific core checks passed across all arms. Three anonymous reviewers supplied 12 locked task judgments.
- **Anonymous Agent results retained:** T02 unanimously favors structure + action (moderate); T01 ranks baseline and structure above it (moderate/weak); T03–T05 are mixed/weak or tied; T06 ties, with eight matching pixel-condition captures.
- **Human product-owner acceptance:** in a separate, nonblind qualitative evaluation, the owner consistently prefers structure + action for overall UI impression, smoother perceived space and palette fit. The owner concludes that the added constraints meaningfully affected Agent choices and improved personally perceptible UI quality.
- **Boundaries:** per-cell n=1, one product family, fixed authorized materials and instruction ablations. No broader model-general probability or universal aesthetic gain is established. The owner judgment does not overwrite the blind Agent rankings.
- **Provenance:** [full post-release findings on current main](https://github.com/D1ChangGeng/UI-Spec-Studio/blob/main/docs/experiments/design-evidence/RESULTS-v1.14.0.md) · [machine-readable trace and source hashes](https://github.com/D1ChangGeng/UI-Spec-Studio/blob/main/docs/evidence/v1.14.0/empirical-findings.json).

**Release integrity:** the original v1.14.0 tag, source and standalone archives, and asset digests are unchanged. Only release-description text and post-release documentation are updated.
