# UI Spec Studio 1.14.0 — Multiscale design evidence and action

Connect intended experience, actual research, professional judgment, mature
resource adoption and real-use checks through a multiscale design evidence map.
**The method and structural helpers are delivered; controlled three-arm Agent
experiments remain unexecuted and general design-quality gains are unverified.**

## Design method

- Connect L0–L5 scales with state/time, conditions, dependencies and provenance.
- Challenge initial coverage through user tasks and real product discoveries.
- Use seven evidence-linked relations for consequential design decisions.
- Keep research, adoption, verification and approval as separate scoped facts.
- Let important gaps drive actual next actions and limit only dependent commitments.
- Extend existing records with Overview, Detail and Execution views; serialization
  and helper use remain optional, with depth proportional to design impact.
- Preserve all previous runtime knowledge and the eight-reference reading contract.

## Tools and evidence

A standard-library, read-only checker validates declarations and local references;
it does not inspect pixels, authenticate research or approve visual quality.
The experiment preparation kit freezes the exact v1.13 baseline, three isolated
instruction arms and six matched task prompts without claiming executed runs.
