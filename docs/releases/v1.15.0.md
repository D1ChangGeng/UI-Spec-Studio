# UI Spec Studio 1.15.0 — Structural observation, Agent judgment, revisable evidence

The structural inspector reports what is represented, not what is professionally
sufficient, correct, ready, or complete.

## Changes

- Separate four responsibilities: current design map, structural observation,
  Agent judgment/execution and independently scoped verification/acceptance.
- Remove mechanical candidate-count, evidence-domain, global freshness and
  action/gap adjudication. Preserve those concerns as professional Agent guidance.
- Replace aggregate helper pass/ok/satisfied output with readability, field/reference
  facts, declared records, separate exceptions and candidate coverage hints.
- Keep theoretical categories distinct from actual task applicability. The 16-category
  vocabulary uses explicit tags only and does not create requirements.
- Keep Manifest queries independent from project phase. Legacy modes are display
  aliases; explicit targets and derived inventory combinations remain distinct.
- Support Current Design Model, Meaningful Revisions and Evidence Archive without
  auto-progress, global invalidation or loading old judgments as current choices.
- Keep inspectors read-only and path-safe. A separate helper verifies local SHA-256.
- Initialize unconfirmed empty environment/scope records and return factual catalog
  observations rather than a generated next action.

The report output intentionally changes. Exit 0 means structural inspection ran,
including a readable record with findings; exit 2 identifies input/read problems.
Independent engineering assertions retain their narrowly scoped pass/fail behavior.
