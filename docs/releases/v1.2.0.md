# UI Spec Studio 1.2.0

A connected UI/UX knowledge practice: generate a design, control its realization
and explain its result.

## Professional capabilities

- Connect user understanding, expression concept, representation, visual grammar,
  materials, implementation and observed outcome.
- Expand typography, color, composition, depth, imagery and native-surface craft.
- Coordinate attention over time while preserving interactive control and real state.
- Read references and diagnose results at whole, relationship and detail scales.
- Carry meaning, structure, visual quality and behavior/timing through integration.
- Reuse six conditional technique patterns with editable realization and boundaries.

The established workflow, optional shape, six common required references and
host/skill responsibilities remain intact. Screen-based documents and visual
explanations use the same practice with medium-specific realization.

## A designed publishing surface

The English and Chinese READMEs apply the revised skill: a reader-led sequence,
copyable installation, native explanations and original editable artwork with
light/dark and narrow compositions. Source, design rationale and browser-check
conditions are included.

## Install

```bash
npx skills add https://github.com/D1ChangGeng/UI-Spec-Studio/tree/v1.2.0 --skill ui-spec
```

## Distribution and assurance

Assets include the complete repository, standalone skill, per-file inventory and
SHA-256 checksums. CI runs deterministic regression, publication rendering and
standard installation gates before release. Release assets are downloaded and
compared with the build before publication.

The checks establish packaging, tooling and the specific rendered artifact.
Agent understanding and design outcomes in other products remain task-specific.
See the Actions run, docs/EVALUATION.md and docs/design/README-SPEC.md for scope.
