## What this version ships

The main agent keeps the complete product goal, the formal UI SPEC, pivotal visual decisions, overall integration and final quality responsibility. Independent research can explore mature sources, actually inspect demonstrations, compare meaningful alternatives and return curated evidence with its unknowns. The primary reviews consequential evidence before adoption. A bounded integration task starts from a selected source, protected design relationships and explicit implementation boundaries; unresolved design stays with the primary.

The complete portable Skill preserves its 37-file foundation, eight required references, adaptive formal increments, observable design events and the v1.19 mature-source/default-deny construction rules. Existing neutral inspectors continue to describe records without certifying visual quality.

The optional Codex adapter installs all four roles through one explicit installation action:

| Role | Responsibility |
| --- | --- |
| `ui_researcher` | Research, compare and curate inspectable sources and evidence for the primary. |
| `ui_integrator` | Integrate an already selected mature source within a bounded authorized contract. |
| `ui_challenger` | Independently challenge consequential assumptions and identify counterevidence when useful. |
| `ui_experience_observer` | Observe complex GUI behavior and continuity in an independent context when useful. |

Installation makes all four roles available. Invocation follows the task; it does not require all roles on every project. Models, tools and permissions come from the host. The adapter includes ownership-aware install, upgrade and uninstall, a checked launcher and a local environment doctor. Unrelated configuration and manually modified files remain protected by their existing ownership checks.

## Distributions and installation

The existing release build produces three separate archives plus `contents.json` and `SHA256SUMS.txt`:

| Asset | Contents |
| --- | --- |
| `ui-spec-1.20.0.zip` | The complete portable `ui-spec` Skill. |
| `ui-spec-codex-1.20.0.zip` | The standalone Codex adapter, all four role files, installer, launcher, doctor, model guidance and license. |
| `ui-spec-studio-1.20.0.zip` | Complete source and retained public evidence, including reconstructable product and review snapshots. |

The portable Skill's documented pinned install command is:

```sh
npx skills add https://github.com/D1ChangGeng/UI-Spec-Studio/tree/v1.20.0 --skill ui-spec
```

After extracting the standalone adapter, run from its `ui-spec-codex/` directory:

```sh
python install.py install --project /path/to/product --dry-run
python install.py install --project /path/to/product
python install.py status --project /path/to/product
```

Use the environment that actually runs Codex. Windows and WSL have separate project/user configuration locations. The [adapter guide](../../integrations/codex/README.md) documents ownership, upgrades, launcher behavior and host compatibility.
