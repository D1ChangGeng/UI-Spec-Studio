# UI Spec Studio v1.20.2 — Guided Terminal Installer & Reversible Migration

## Installer UX

- Adopt the mature, MIT-licensed `@clack/prompts` terminal UI for a guided, bilingual (`--lang en|zh`) installation with meaningful phases, environment summaries, issue handling and completion feedback.
- Keep no-TTY/CI output deterministic and machine-readable. The prompt package is an optional npm dependency: the required runtime Skill and native Codex adapter remain self-contained.
- Do not present fictitious network download progress: npm downloads the small release archive before the installation process starts. Verification, local copy and native adapter registration represent actual performed work.

## Legacy interoperability

- Detect existing copied `ui-spec` directories and linked/junction-installed Skills without following or modifying links outside the selected install path.
- On interactive terminals, explicitly offer file-identical adoption, reversible backup-and-update, or no changes.
- Headless consumers use `--migrate` for backup-and-update or `--adopt` for byte-identical legacy copies. `--yes` alone is not overwrite authorization.
- Keep original versions in a host-scoped backup directory that is not scanned as a Skill; restore the former installation on uninstall. For file-identical adoption, removing this installer's ownership receipt leaves original Skill files intact.
- Preserve strict integrity enforcement for managed installations, exclusive install locking, and rollback of the Skill files on native adapter failures.
- Retain all four Codex roles as separately owned native configurations. Windows and POSIX scopes remain explicit.

## Compatibility and verification

The v1.20.1 portable design method and its full 37-file Skill payload are unchanged except for the distribution metadata version. No additional model, browser or agent permission is installed. Unit, cross-platform installer smoke tests and the actual public release-asset installation must complete before claiming v1.20.2 published.
