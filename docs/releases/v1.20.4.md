# UI Spec Studio v1.20.4 — First trusted npm publishing validation

## Release objective

Publish a new immutable, version-aligned CLI and Skill distribution using the existing reviewed GitHub Actions release process, and use this version to validate the newly configured npm **GitHub Actions Trusted Publisher** (OIDC). This release follows the successful public manual bootstrap of `ui-spec-studio@1.20.3`.

This is a distribution and validation patch, **not** a redesign of the UI Spec Studio professional method.

## Changes included

- Align `VERSION`, the installed `skills/ui-spec/SKILL.md` metadata and the npm `installer/package.json` version to `1.20.4`.
- Include the merged post-publication fixes: the official `npx --yes ui-spec-studio@latest` entry point, safe legacy Skill migration, idempotent manual bootstrap readback and bounded public npm registry verification following CI publication.
- Keep the existing 37-file Skill payload structure and the four Codex-native roles; no new agent execution permission, browser access, or model-runtime claim is introduced.

## Required verification — not claimed until observed

1. `Validate and release` passes all test, installer portability, README rendering, scenario and release-asset gates on the exact published `main` commit.
2. The GitHub release tag `v1.20.4` identifies that commit, the release is public and its asset SHA-256 readback passes.
3. `.github/workflows/npm-publish.yml` performs **a real new-version npm publish using GitHub OIDC** (no long-lived npm token), not just a successful skipped job. npm accepts `ui-spec-studio@1.20.4`.
4. The public registry version and `latest` dist-tag point to `1.20.4`; its SHA-512 matches the exact immutable GitHub `ui-spec-installer.tgz` release asset.
5. The public npm-named installer passes clean install, four-role registration, old unowned Skill backup/migration and uninstall restoration. Confirm published npm provenance and the npm Trusted Publisher status independently.

Do **not** republish the same semver if the publish command already succeeded but immediate registry readback remains pending. Recheck the read-only registry state.

## Official installation

```powershell
npx --yes ui-spec-studio@latest install --agent codex --global --migrate --lang zh
```

The command installs the official npm package only after the registry confirms the new version. The version-independent CLI remains compatible with the previous verified `1.20.3` distribution.

## Evidence boundaries

Automated installation and registry-integrity checks prove their tested distribution paths only. Real product visual quality, the effectiveness of Codex models and cross-environment agent behavior are independent acceptance subjects.
