# UI Spec Studio v1.20.6 — Installer UX writing for Skill users

## Purpose

The installer serves someone who wants to **use UI Spec Studio in a coding tool**, not someone maintaining the package. The interactive experience focuses on the choice, its consequences and the result. The professional design guidance in the installed 37-file Skill remains unchanged except for the version scalar.

## User-facing interaction

| Step | English | 简体中文 | Required behavior |
| --- | --- | --- | --- |
| Choose tool | Which tool will you use? | 在哪个工具中使用？ | Show Codex, Claude Code, Cursor and OpenCode by product name |
| Choose scope | Where should it be installed? | 安装到哪里？ | This project or all projects for the current user |
| Resolve existing | What would you like to do with the existing version? | 如何处理已有版本？ | Reuse identical files, back up and update, or keep existing; backup restores on uninstall |
| Actual progress | Installing UI Spec Studio | 正在安装 UI Spec Studio | Report real installation and verification; show Codex role setup only for Codex |
| Completion | Installed / Updated / Already up to date / Uninstalled / Previous installation restored | 已安装 / 已更新 / 已是当前版本 / 已卸载 / 已恢复原安装 | Match the action, show destination and backup path only when relevant |

The interactive flow no longer describes npm internals, GitHub repository-cloning behavior, file inventories, adapter implementation or duplicate install plans. Security failures retain explicit, actionable details. `--help --lang zh` renders user-focused Chinese help; non-interactive JSON keys and values remain unchanged.

## Acceptance requirements (not claimed until observed)

- Run full Linux, Windows and macOS installer compatibility checks, deterministic packaging, full unit tests and README/scenario CI.
- Exercise real Clack terminal interactions, English and Chinese, for selection, keep, migration, original-file restoration and progress text.
- Preserve no implicit overwrites, the original user's files, Codex native roles, precise ownership receipts, installation locking and rollback.
- Publish immutable GitHub `v1.20.6` from the exact validated main commit, then publish `ui-spec-studio@1.20.6` via the configured npm Trusted Publisher using OIDC, with public SHA-512, latest, fresh-cache real CLI and reversible legacy migration readback.
- Do not move or republish any previous release tags or npm package versions.

## Official installation

```powershell
npx --yes ui-spec-studio@latest
```

For explicit global Codex installation with an older unowned Skill directory:

```powershell
npx --yes ui-spec-studio@latest install --agent codex --global --migrate --lang zh
```
