# UI Spec Studio v1.21.0 — Wide High-Craft Discovery, Deep Reuse & Taste Calibration

## What this version ships

Version `1.21.0` systematically tunes the entire `ui-spec` Skill and its optional Codex four-role adapter around three core capabilities—**wide high-grade UI resource discovery**, **deep source-preserving reuse & craft-elevating improvement**, and **actionable UI design taste**—while consolidating runtime structure and preserving every existing safety, continuity and neutral-inspector guarantee.

### 1. Wide high-grade UI resource discovery
- **80 live-verified resource leads:** expands `assets/resource-catalog.json` from 37 to **80** dated entries (preserving all 37 original `2026-10-24` leads verbatim and adding 43 `2026-11-18` craft-focused registries, systems, primitives, motion, data-viz, typography, icon/illustration, shader/3D and editor leads), with 100% (`80/80`) neutral descriptive `craft_profile` metadata.
- **Upgraded neutral local lookup (`scripts/find_resources.py`):** concrete code-stack filters (`react`, `vue`, `svelte`, `solid`, `web-components`, `vanilla-web`, etc.) now include `framework-neutral`, `multi-framework` and `multi-runtime` leads; adds safe ASCII word-boundary & singular/plural query matching, `adoption_notes` and `craft_profile` search coverage, and `total_matches`/`truncated` metadata without introducing scores or rankings.
- **4-tier discovery architecture & Generic-Default Rejection Floor:** structures proactive sourcing across curated craft registries, mature systems/primitives, specialist motion/chart/3D/editor ecosystems, and open exploration, rejecting unexamined default scaffolds when better-fitting craft exists.

### 2. Deep reuse and craft-elevating improvement
- **Five permitted deep-reuse operations** cleanly separated from prohibited original UI construction (closed `W1`–`W3` allowlist): *Source-Preserving De-Templating*, *Canonical Token-Plane & Multi-Source Cascade Harmonization*, *Adopted-Component Rendering-Fidelity & Ergonomic Repair*, *Source-Derived Architectural Porting & Weight-Stripping* (requiring inspected upstream source code, derivative-permitting license with attribution/notices, and checking native-stack equivalents first), and *Craft-Elevating State & Accessibility Completion*.
- **Concrete recipes and integration rules** in `patterns.md`, `examples.md`, `integration.md`, and `evidence-records.md` showing how to harmonize tokens, repair rendering/ergonomic seams, and verify craft survival after integration.

### 3. UI design taste and aesthetic discrimination
- **Diagnostic AI-slop failure signatures & operational craft calibrations** in `principles.md` (with zero dogmatic aesthetic bans), covering optical typographic tuning, proportion/rhythm, surface depth & hairline contrast, color restraint, visual density, and asset/icon alignment.
- **Optical dark/light re-authoring & tactile motion personality** in `interaction-and-variants.md`, paired with editorial copy craft (`content-design.md`) and asset-to-interface cohesion (`visual-assets.md`).
- **Taste-Critique -> Upgrade -> Re-Inspect loop & Target-Demo vs. Integrated-App Visual Delta** across `analysis.md`, `workflow.md`, and `verification.md`, backed by empirical regression guardrails.

### 4. Whole-Skill consolidation & Codex four-role alignment
- **38-file portable Skill:** extracts nine scattered v1.20 delegation blocks into one conditional reference (`skills/ui-spec/references/delegation.md`), reducing `SKILL.md` by 53.1% while keeping all eight common references complete and readable in full.
- **Upgraded Codex adapter (`integrations/codex/`):** aligns `ui_researcher`, `ui_integrator`, `ui_challenger`, and `ui_experience_observer` with v1.21 discovery, deep-reuse boundaries, and taste critique while preserving unconditional eight-common-reference reading, ownership-aware installation, and SHA-256 verification.

## Distributions and installation

The official version-independent installer command remains:

```powershell
npx --yes ui-spec-studio@latest
```

For explicit global Codex installation or safe migration of an unmanaged legacy Skill:

```powershell
npx --yes ui-spec-studio@latest install --agent codex --global --migrate --lang zh
```

The deterministic release build produces:

| Asset | Contents |
| --- | --- |
| `ui-spec-installer.tgz` | Lightweight unified installer carrying the 38-file portable Skill and supported Harness adapters. |
| `ui-spec-1.21.0.zip` | Complete portable `ui-spec` Skill (38 files). |
| `ui-spec-codex-1.21.0.zip` | Standalone Codex four-role adapter, installer, launcher, doctor and license. |
| `ui-spec-studio-1.21.0.zip` | Complete repository source and preserved historical evidence. |
| `contents.json`, `SHA256SUMS.txt` | Per-file inventory and release artifact checksums. |

Pinned GitHub Release fallback commands (when npm registry resolution is unavailable):

```bash
npx --yes https://github.com/D1ChangGeng/UI-Spec-Studio/releases/download/v1.21.0/ui-spec-installer.tgz install --agent codex
npx skills add https://github.com/D1ChangGeng/UI-Spec-Studio/releases/download/v1.21.0/ui-spec-1.21.0.zip --skill ui-spec -a codex
```
