# UI Spec Studio v1.22.0 — Sustainable Long-Term Product & Engineering Loop

## What this version ships

Version 1.22.0 builds directly on `v1.21.0` (retaining 100% of its 4-tier wide high-craft discovery, 80-entry neutral catalog, five permitted deep-reuse operations, operational UI taste calibrations and centralized `references/delegation.md`) to strengthen the `ui-spec` iterative loop (`init`, optional `shape`, `iterate`, `audit`, `finish`) for long-lived, multi-session, multi-engineer brownfield product development across five connected responsibilities—without adding new workflow phases, ticket state machines, fixed quotas, staleness timers or routine-continuation approval gates:

1. **Cross-session continuation and anti-relitigation:** Re-entry reconciles the `Overall Product Goal`, `Current Design Model` and live `Current Product UI` so fresh host sessions inherit settled foundations and scoped approvals without redundant discovery, while reopening claims only when user intent, rendered evidence or operating conditions change. Completed increments and interrupted mid-SPEC handoffs leave explicit runnable entry paths, distinct `implemented`/`inspected`/`approved`/`connected`/`verified` scope facts, open obligations and next actions.
2. **Living multi-SPEC horizon and safe retirement:** Formal increments are governed as an evolving horizon (`candidate`, `active`, `completed`, `superseded`, `consolidated`, `retired`) ordered by user value, cross-SPEC dependencies, representative anchor-slice leverage and parallel-worktree boundaries. Consolidating, superseding or retiring SPECs or UI surfaces accounts for where valid user task paths and unresolved quality obligations move and removes dead entry points.
3. **Brownfield engineering and contract drift reconciliation:** Between-round code commits, backend schema/permission updates, emergency UI hotfixes and requirement pivots are diagnosed through four causal paths—preserving compatible refactors and landed functional/accessibility/security fixes while adopting authoritative service truth and repairing visual craft or default-deny provenance on top of live implementations.
4. **Staged shared-system migrations and proportional regression:** Multi-increment upgrades to typography, semantic tokens, layout shells or mature component families prove fit on a representative anchor slice first, establish explicit coexistence boundaries and scoped compatibility bridges strictly under default-deny W1–W3 rules, track legacy foundation decommission, and focus regression on the primary changed slice, migration seams and high-risk extremum consumers rather than `O(entire app)` re-audits.
5. **Bounded `O(active product)` compaction and debt anti-evaporation:** Superseded candidate comparisons, closed intermediate trials and retired surface details compact into causal `Meaningful Revisions` and cold-linked `Evidence Archive` records while keeping four explicit obligation classes—**Visual & Craft Debt**, **Provisional Probe & Migration Bridge Debt**, **Integration & Contract Debt** and **Verification Scope Debt**—visible until verified closed, carried with explicit reopen triggers or retired with documented product cause.

## Distributions and installation

The official version-independent installer command remains:

```powershell
npx --yes ui-spec-studio@latest
```

Direct installation examples for Codex or Antigravity:

```powershell
npx --yes ui-spec-studio@latest install --agent codex --global --migrate --lang zh
npx --yes ui-spec-studio@latest install --agent antigravity
npx --yes ui-spec-studio@latest install --agent antigravity --global
```

The deterministic release build produces:

| Asset | Contents |
| --- | --- |
| `ui-spec-installer.tgz` | Lightweight unified installer carrying the 38-file portable Skill and supported Harness adapters (Codex, Claude Code, Cursor, OpenCode, Antigravity). |
| `ui-spec-1.22.0.zip` | Complete portable `ui-spec` Skill (38 files). |
| `ui-spec-codex-1.22.0.zip` | Standalone Codex four-role adapter, installer, launcher, doctor and license. |
| `ui-spec-studio-1.22.0.zip` | Complete repository source and preserved historical evidence. |
| `contents.json`, `SHA256SUMS.txt` | Per-file inventory and release artifact checksums. |

Pinned GitHub Release fallback commands (when npm registry resolution is unavailable):

```bash
npx --yes https://github.com/D1ChangGeng/UI-Spec-Studio/releases/download/v1.22.0/ui-spec-installer.tgz install --agent codex
npx --yes https://github.com/D1ChangGeng/UI-Spec-Studio/releases/download/v1.22.0/ui-spec-installer.tgz install --agent antigravity
```
