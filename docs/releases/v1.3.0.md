# UI Spec Studio 1.3.0

Discover useful work across the UI ecosystem, assess its value, and make it part
of a coherent product.

## Resource discovery and reuse

- Pair requirement-led search with opportunity-led exploration.
- Read exact demos, variants, exported configuration and implementation contracts.
- Choose direct adoption, adaptation, composition, technique transfer or original
  implementation by design fit, necessary behavior, rights and total lifecycle cost.
- Validate the assembled result and retain scoped adoption knowledge.
- Use an included capability catalog of 37 resources and 7 access mechanisms,
  with original research dates, sources and explicit evidence scope.
- Query the catalog locally with the optional standard-library lookup helper.

The method participates in Shape, Iterate, Audit and Finish. Six common references
remain the professional foundation. Catalog details support discovery; actual
project behavior and visual evidence determine acceptance.

## Install

```bash
npx skills add https://github.com/D1ChangGeng/UI-Spec-Studio/tree/v1.3.0 --skill ui-spec
```
