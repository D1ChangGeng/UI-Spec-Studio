# UI Spec Studio 1.4.0

Reference-grounded design that begins with the product people expect to use.

## Product intent and decisions

- Make mature design foundations the default starting point for substantial work,
  selecting the highest appropriate reuse level and preserving coherent decisions.
- Apply theory and resource knowledge together through actual search, browsing,
  comparison, adaptation and verification.

- Infer the primary interaction model from first action, working object, repeated
  loop, continuation and result, including purposeful hybrid models.
- Research mature product conventions and concrete engineering resources while
  meaningful design choices remain open.
- Preserve functional and engineering assets; evaluate visual reuse against the
  target and actual approval.
- Offer a concise recommendation and distinct options for unresolved high-impact
  directions, with explicit one-shot and delegated-work behavior.
- Pair each substantive SPEC with a surface-level design/resource decision trace,
  connecting reference, choice, implementation and observed result.
- Verify primary-task continuity, responsiveness, access and the assembled output.

The six-reference foundation, optional Shape, continuous Iterate and complete
Finish remain intact. A worked research-product scenario demonstrates two models,
real source reuse, a visible decision panel and testable interactions.

## Install

```bash
npx skills add https://github.com/D1ChangGeng/UI-Spec-Studio/tree/v1.4.0 --skill ui-spec
```

## Assurance

CI gates cover deterministic regressions, portable installation, README rendering
and the authored HTTP-browser scenario. Versioned source, standalone skill, content
inventory and checksums are read back before publication. The scenario validates
its own implementation; actual project acceptance and model-wide effectiveness
retain their separate evidence requirements.
