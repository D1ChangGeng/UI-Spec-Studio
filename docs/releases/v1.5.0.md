# UI Spec Studio 1.5.0

Visual Assets & Asset Engineering is part of the common design foundation.

Assets and page structure develop together. The skill now covers research,
selection, production, editable masters, delivery variants, integration and
family-specific verification for identity/icons, type/glyphs, 2D, spatial and
dynamic material. It separates production routes from static, timed or real-time
delivery, and retains actual source rights and tool-capability boundaries.

The update adds a focused primary-source map, optional asset record and a real
browser review fixture. Seven common references provide the professional context;
optional Shape, continuous Iterate and complete Finish remain the working path.
The accepted bilingual README layout and original publication assets are preserved.

```bash
npx skills add https://github.com/D1ChangGeng/UI-Spec-Studio/tree/v1.5.0 --skill ui-spec
```

Release gates cover package regressions, cross-platform execution, installation,
publication rendering and the product/asset browser fixtures. Assets include the
source bundle, standalone skill, content inventory and SHA-256 checksums. Read CI
and the review document for executed scope; specialist production and project
acceptance retain their own evidence requirements.
