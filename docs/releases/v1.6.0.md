# UI Spec Studio 1.6.0

Content Design, UX Writing and Typography join the complete UI design-engineering foundation.

The new shared reference connects user understanding, information distribution, Voice and Tone, wording, typography, states, accessibility, localization and real product authority. Design and content influence each other across all phases. An optional content decision record preserves consequential wording and its approved sources; the content-source map points to primary GOV.UK, Microsoft, IBM Carbon and W3C guidance.

A focused bilingual editor fixture demonstrates page copy, input labels, validation, progress, success, local storage, failure recovery and locale/viewport rhythm. Release gates validate actual browser behavior alongside existing visual assets and product intent scenarios.
