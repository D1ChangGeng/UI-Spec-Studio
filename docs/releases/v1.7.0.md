# UI Spec Studio 1.7.0

Visual Reasoning & Visual Inspection connects professional design knowledge to
the interface people actually see and use.

The method now follows consequential visual choices through resource research,
selection, composition, asset production, implementation and acceptance. Agents
view exact candidates, explain perceptible relationships in product context and
inspect the assembled result. Source-resource quality, composition quality and
actual runtime quality each receive their own observation.

Temporal Visual Inspection expands that work from individual frames to meaningful
episodes and connected journeys. Observation windows follow the event: a complete
micro-interaction, a loop and its seam, an asynchronous wait-to-result, or linked
navigation and return. Seven qualities guide judgment: temporal continuity, object
continuity, motion quality, dynamic composition, state/feedback alignment, temporal
stability and cross-view continuity.

Capture conditions and actual viewing remain explicit. Normal-speed observation,
ordered frames, keyframes and controlled-time probes support different questions.
Visible evidence supports appearance judgments; source, state and runtime evidence
explain causes and verify behavior. Important decisions connect inspected evidence,
interpretation, implementation and a rechecked result, with approval retaining its
actual scope.

A runnable temporal example and browser capture workflow join the existing product,
asset, content and publication checks. The fixture supplies chronological evidence
for its own interactions; executed visual inspection and engineering results are
recorded separately in the version review and CI output.

The eight common references and established `init → iterate → finish` path remain,
with optional `shape` and continuous `audit`. Detailed methods stay with their
responsible reference, and observation depth follows the design decision.
