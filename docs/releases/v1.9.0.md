# UI Spec Studio 1.9.0

## Mature implementation carries the quality target

This release connects product visual and interaction maturity to the resources
actually used in the product. General UI starts from suitable mature structures,
systems, blocks, components, assets and motion. Reference study and implementation
selection proceed together while useful discoveries can improve the design.

Consequential choices move through four distinct observations: the relevant
reference, the candidate's original demonstration, a local trial using current
product conditions, and the integrated interface/journey. Local trials expose
content, font, theme, state and runtime mismatches before expanding implementation.

Adaptation preserves the valuable mechanisms that justified adoption. Configuration,
composition, themes and business adapters can carry genuine reuse. New generic UI
addresses an identified gap; substantial mechanism changes carry their own quality
and engineering verification. Records distinguish studied, compared, trialed and
adopted work and show which actual implementation carries the important experience.

When quality falls short, diagnose resource fit, adaptation, content, composition
or target relevance. Make remaining gaps and necessary scope decisions inspectable.
For material access gaps, request precise normal authorized user assistance and
continue the analysis after receiving the evidence or resource.

The eight common references, `init → iterate → finish`, optional `shape`, existing
host authority and lightweight records remain. No new installed runtime dependency
or fixed reuse percentage is introduced.
