# UI review

## Scope and condition

Routes/states, viewport, browser, theme, locale, data identity, revision and actual entry path.

## Observation

Whole-frame hierarchy, core scale and occupancy, optical balance, whitespace,
readability, shared anchors, scroll ownership and reachable controls.

## Interaction

Task steps, focus/input/selection retention, transitions, error/retry and result.

## Findings and repair

Finding | evidence | affected rule/task | responsible layer | repair | retest

## Result

Executed checks, current status, recorded user approval, evidence and remaining conditions.

## Content review

Identify the current task question, intended message, source fact, actual wording/state, typography/layout result, locale coverage and observed behavior. Scope editorial judgment, user comprehension and business approval separately.

## Runtime and maintenance observations

When relevant, record input feedback, usable result and confirmed completion under
stated device/network/data conditions; motion and scroll continuity; preparation cost;
effective template/override content; batch outcomes and recovery. State the metric's
actual boundary and compare equivalent conditions. Link traces and runtime evidence.
